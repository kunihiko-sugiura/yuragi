# ゆらぎ

ブラウザで鳴り続けるアンビエント音楽です。周期の異なる6つのループを重ねているので、同じ並びには二度と戻りません。Brian Eno『Music for Airports』と同じ考え方です。

操作は音色の切り替え（ピアノ的 / パッド的）だけです。画面下の2つの波形アイコンで選びます。再生ボタンも、音量や速さのつまみもありません。

## 聴き方

`index.html` をブラウザで開くと鳴り始めます。ブラウザが操作なしの発音を止めている場合は、画面のどこかをクリックするか、キーを押すと鳴り始めます。サーバーもビルドも要りません。

調律と音色は URL で切り替えられます。

| URL | 内容 |
|---|---|
| `index.html` | 平均律（既定） |
| `index.html?tuning=pyth` | ピタゴラス音律。4度と5度が純正 |
| `index.html?tuning=just` | 純正律。3度が純正 |
| `index.html?a=soft` | ピアノ的な音色を改訂前の丸い音色にする（聴き比べ用） |

## しくみ

- 音階は D♭ メジャー・ペンタトニック。半音を含まないので、どう重なっても濁りません
- 6つの声部が 17.3〜31.7 秒の周期でそれぞれ1音ずつ鳴らします。周期は互いに割り切れない値なので、全体が同じ配置に戻るのは約60万年後です
- 音は Web Audio API の加算合成だけで作っています。外部の音声ファイルは使いません
- ピッチ、倍音の音量、1音ごとの強さや長さに、気づかない程度の不規則なゆらぎを加えています。素のサイン波の冷たさを消すためです
- 画面には、音が鳴るたびに声部ごとの位置で円がにじんで消えます

詳しい設計と数値の根拠は [ambient-loop-spec.md](ambient-loop-spec.md) にあります。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 再生ページ |
| `app.js` | AudioContext の開始、音色の切り替え、描画 |
| `engine.js` | 音の生成。数値はすべて冒頭の `CONFIG` にまとめてあります |
| `types.d.ts` | JSDoc から参照する型定義（型検査専用。ブラウザは読みません） |
| `ambient-loop-spec.md` | 仕様 v2 |
| `ambient-loop-spec.v1.md` | 仕様 v1（改訂前） |
| `verify.html` / `verify-page.js` / `verify.mjs` | 自動検証 |

## 音を調整する

`engine.js` 冒頭の `CONFIG` を書き換えて、ページを再読み込みします。調整の候補は仕様書の「耳で決めること」に優先順で並べてあります。

| 調整したいこと | 場所 |
|---|---|
| 音色ごとの音量 | `timbres.piano.level` / `timbres.pad.level` |
| ピアノの響きの長さ | `timbres.piano.decay` |
| うなりの速さ | `timbres.*.beatHz` |
| 明るさ | `timbres.*.cutoff`（基音の何倍でローパスをかけるか） |
| 残響の量と長さ | `reverb.wet` / `reverb.seconds` |
| ゆらぎの幅 | `yuragi` |

## 型検査

JavaScript のまま、JSDoc の型注釈を TypeScript で検査しています。ビルドはありません。

```sh
npm install
npm run typecheck
```

## 検証

Node.js 22 以上と Google Chrome が必要です。

```sh
node verify.mjs --live
```

ヘッドレスの Chrome で次を確かめます。全項目が通れば終了コード 0 を返します。

- 5分間をオフラインで描画し、音が出ていること、NaN がないこと、ピークが −3 dBFS 未満であること
- 周期と1音ごとのゆらぎが仕様の範囲に収まること
- 音階の6音が鳴り、音階外の音が鳴っていないこと
- 再生ごとに発音の並びが変わること
- 実際のページで、最初の操作で鳴り始めること、音色の切り替えが動くこと、コンソールにエラーが出ないこと

`--live` を外すとオフライン描画の検証だけを行います。`SECONDS=60 node verify.mjs` のように描画時間を短くすると早く終わります。スクリーンショットは `verify-out/` に保存されます。

検証で分かるのは壊れていないことまでです。心地よく聴こえるかどうかは、実際に聴いて確かめてください。

## 制限

- iOS で消音スイッチが入っていると音が出ません
- 画面ロック中も鳴り続けるかどうかは保証しません
- 動作を確かめたのは macOS の Chrome だけです。Safari、Firefox、スマートフォンでは未確認です
